# AUC Route Network Analyzer

## Project Description

The AUC Route Network Analyzer is a C++ application designed to represent and analyze the network of buildings and walking paths across the AUC campus.

The application will represent buildings and important locations as vertices in a weighted, undirected graph, with edges representing the paths connecting them.

The project will use graph algorithms such as BFS, DFS, Dijkstra's shortest-path algorithm, and Minimum Spanning Tree algorithms to explore the network, find shortest routes, and analyze connectivity.
